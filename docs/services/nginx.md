#### Web-Сервер Nginx
- Расположение: `services/nginx/default.nix`
- Модули: `services/nginx/default.nix` `services/nginx/domain.nix`
- Использующееся опции: `services.nginx` `security.acme`
- Зависимости: отсутствуют

**Ключевые параметры**:
- `imports = [ ./domain.nix ]` - если домена нету то нужно удалить либо закоментировать
- `services.nginx.virtualHosts."sophron.ru"` - если используется иной домен то нужно заменить название
- `services.nginx.virtualHosts."sophron.ru".root` - если нету главной страницы то необходимо либо убрать либо добавить свою страницу.
- `email` - почта которая будет использоваться для acme сертификации
- `domain` - домен которому будут выдаваться сертификаты

**Описание**:
Сервис позволяющий перенаправлять на нужную страницу для доменов, либо локальных, либо общественных.

**Принцип**:
В `default.nix` настраивается сертификация домена и так же его основная страница
В `domain.nix` включается принятие соглашения, указания домена и так же имен, которым необходимо выдать сертификат

**Проблема**:
Имеется wildcard способ сертифицировать домены, для создания одного сертификата на все домены. Но регистратор beget который использовался для выдачи по какой то причине не работает, по этому регистрация доменов идет обычным способом через указание в `security.acme.certs."${domain}"`.
