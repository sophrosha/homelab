#### VPN сеть TailScale
- Расположение: `services/tailscale.nix`
- Использующееся опции: `boot.initrd.systemd` `services.tailscale` `systemd`
- Зависимости: отсутствуют

**Ключевые параметры**:
Отсутствуют. Сопряжение с аккаунтом происходит через команду `tailscale login`

**Описание**:
Сервис использующий создание Mesh-VPN на протоколе WireGuard, необходим для подключения к серверу извне и работы с ним из дома.

**Принцип**:
Сервис включен через стандартную опцию, дополнительные настройки для режима фаервола указаны через `systemd`.
