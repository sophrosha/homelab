#### NextCloud
- Расположение: `services/nextcloud.nix`
- Использующееся опции: `services.nextcloud` `nginx.virtualHosts`
- Зависимости: наличие nginx

**Ключевые параметры**:
- `services.nextcloud.hostName` - указание trusted домена через который nextcloud будет принимать подключения, если подключение будет идти напрямую через айпи или порт то nextcloud будет выдавать ошибку
- `services.nextcloud.maxUploadSize` - Максимальный размер загрузки файла, если места мало то необходимо ставить меньший размер

**Описание**:
Сервис экосистема с предустановкой программ, хранением файлов и собственным мессенджером.

**Принцип**:
Nextcloud запущен с trusted доменом и настроенной базой данный. Nginx только перенаправляет подключение и дает SSL соединение.
