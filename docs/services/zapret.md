#### Запрет для обхода ТСПУ
- Расположение: `services/zapret.nix`
- Использующееся опции: `networking.nftables` `services.zapret-discord-youtube`
- Зависимости: наличие в `flake.nix`

**Ключевые параметры**:
- `configName` - включает конфиг который подходит для вашего провайдера

**Описание**:
Данный сервис позволяет обходить блокировки на стороне Роскомнадзор получая доступ к заблокированным ресурсам. `zapret-discord-youtube` это неофициальный пакет, по этому его работа происходит через импортирование модуля из `flake.nix`.

**Принцип**:
Для работы сервиса необходим nftables который включен и настройка сервиса с выбором конфигурации.
