#### Сервис аналитики Grafana
- Расположение: `services/grafana.nix`
- Использующееся опции: `services.grafana` `services.prometheus` `services.nginx.virtualHosts`
- Зависимости: Наличие sops, nginx

**Ключевые параметры**:
- `services.grafana.settings.server.domain` - изменение домена если необходим другой
- `services.prometheus.exporters.node.enabledCollectors` - изменение включенных коллекторов для необходимых показаний в grafana
- `services.nginx.virtualHosts."grafana.server.local"` - если домен изменен то тут меняем тоже

**Описание**:
Сервис отслеживающий статистику по серверу, его данным и тд. Или иных устройств при наличии добавленных сервисов сбора данных

**Принцип**:
Настроена grafana с секретным ключом который сгенерирован в `secrets.yaml`, настройками домена.
Для получения статистики используется prometheus с экспортером нода для сервера. В будущем будет добавлен экспортер snmp для просмотра данных роутера.

Подключение к сервису происходит по настроенному домену.
