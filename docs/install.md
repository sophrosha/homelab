## Установка и настройка конфигурации
### Установка
Установка подразумевает начальное развертывание конфигурации HomeLab, разметку дисков и настройки базовой конфигурации
#### Начало
Необходимо скачать с сайта nixos.org образ операционной системы в виде LiveCD, и запись ее через существующие программы записи образа на носитель. 

После записи необходимо выбрать флешку в настройках сервера и загрузится в пользователя LiveCD. рекомендуется инициализировать базовую ssh сессию для удобной настройки через компьютер.
#### Разметка и монтирование
На сервере должно находится два диска, представим `/dev/sda` и `/dev/sdb`, `sda` будет основным диском для операционной системы, `sdb` наоборот диском для хранения информации, фильмов, сетевых каталогов samba.

Делаем форматирование(*вы несете отвественность за форматирование и монтирование диска, делайте на свой страх и риск*)
```sh
# Уточняем наличие sda и sdb, если они разные или диск к примеру /dev/nvme0p1 то используете его заменяя два диска
sudo lsblk

# Ставим диску mbr сектор
# o создает dos таблицу, w сохраняет изменения и закрывает программу
sudo fdisk /dev/sda
sudo fdisk /dev/sdb

# Размечаем разделы, для обоих носителей раздел будет 1, так как система устанавливается на старой разметке MBR(dos)
sudo cfdisk /dev/sda
sudo cfdisk /dev/sdb

# Делаем форматирование в ext4
sudo mkfs.ext4 /dev/sda
sudo mkfs.ext4 /dev/sdb

# Монтируем системный диск. 
# Диск для данных будет автоматически примонтирован fstab при последующей перезагрузке после применения конфигурации
sudo mount /dev/sda /mnt

```
#### Инициализация базовой конфигурации
После монтирования диска необходимо скачать репозитории homelab в родительском каталоге liveCD, инициализировать базовую конфигурацию и после чего настроить и применить.
```sh
cd ~
nix-shell -p git --run "git clone https://github.com/sophrosha/homelab"

# Генерируем базовую конфигурацию
sudo nixos-generate-config --root /mnt

# Создаем каталог для размещения конфигурации и копируем его в домашнюю директорию
sudo mkdir -p /mnt/home/server
sudo mkdir /mnt/home/server/disk # создаем каталог для размещения данных второго диска
sudo cp -rv homelab /mnt/home/server/nixosConfigs
```
### Настройка
Настройка подразумевает отключение или подключение необходимых служб, настройки сети, секретов для необходимых сервисов, подключение и создание сертификата домена а так же настройку локальных доменных имен из DNS-Сервера.
#### Базовая настройка
Так как мы развернули конфигурацию в домашней директории то необходимо переместить `hardware-configuration.nix` в `hw-config.nix` и настроить внутри него диски, если установка происходит на том же сервере то данный шаг пропускается. Уже сгенерированный блок с файловой системой удаляем.
```sh
sudo cp -rv /mnt/etc/nixos/hardware-configuration.nix /mnt/home/server/nixosConfigs/hw-config.nix
```

Теперь данный конфиг необходимо настроить для правильного монтирования дисков, а так же подкачки. Необходимо для начала добыть UUID диска, после чего вписать его в шаблонный блок и сохранить.

```sh
sudo blkid
/dev/sda1: UUID="63fd75ba-7f3a-4c41-b679-fc464a305340"
/dev/sdb1: UUID="8ce52a46-9d15-49e9-a1f5-adfb6f4cd1f3"
```

```nix
fileSystems = {
	"/" = {
		device = "/dev/disk/by-uuid/ВПИСЫВАЕМ_UUID_SDA_СЮДА";
		fsType = "ext4";
	};
	"/home/server/disk" = {
		device = "/dev/disk/by-uuid/ВПИСЫВАЕМ_UUID_SDB_СЮДА";
		fsType = "ext4";
		options = [ "nofail" ];
	};
};
```

(Опционально) добавляем файл подкачки
```nix
swapDevices = [
	{
		device = "/var/lib/swapfile";
		size = 8 * 1024; # 8гб
	}
];
```
#### Настройка сети
Если сервер работает на иной подсети роутера или имеет иные данные, то необходимо их поправить в секции networking в `default.nix`
```nix
  networking = {
    hostName = "p5kserv"; # даем имя
    domain = "homeserver.local"; # какой будет домен
    nameservers = [ "127.0.0.1" ]; # Пока не работает локальный DNS, меняем на стандартный 8.8.8.8
    networkmanager.enable = true;

    defaultGateway = "192.168.0.1"; # шлюз роутера
    interfaces.enp2s0 = { # указываем имя устройства
      ipv4.addresses = [
        {
          address = "192.168.0.102"; # адрес сервера
          prefixLength = 24; # маска подсети(тут 255.255.255.0)
        }
      ];
    };
  };
```
#### Генерация секретов
Секреты сервера шифруются sops конфигурацией, для его работы и отсутствия конфликтов с установленными параметрами ключа необходимо создать age ключ, сгенерировать секретный ключ для необходимых сервисов и добавить публичный ключ в `.sops.yaml`
```sh
# Создаем каталог для расположения секретного age ключа и создаем его
sudo mkdir -p /mnt/home/server/.config/sops/age
sudo nix-shell -p age --run "sudo age-keygen -o /mnt/home/server/.config/sops/age/keys.txt"
```

После создания ключа будет вывод публичного ключа который необходимо указать в файле `.sops.yaml`
```yaml
keys:
  - &host ВАШ_ПУБЛИЧНЫЙ_КЛЮЧ
```

Так как grafana использует ключ через sops и называется `grafana_secret` то генерируем ключ и вставляем его в пересозданный `secrets.yaml` так как хранимая информация в зашифрованном виде считается мусором из-за отсутствия нужного секретного ключа
```sh
openssl rand -base64 32
```

после чего пишем в `secrets.yaml`
```yaml
grafana_secret: ваш_секрет
```

и шифруем его
```sh
# На всякий случай перемещаемся в директорию конфигурации
cd /mnt/home/server/nixosConfigs
sudo nix-shell -p sops --run "SOPS_AGE_KEY_FILE=/mnt/home/server/.config/sops/age/keys.txt sops -e -i /mnt/home/server/nixosConfigs/secrets.yaml"

cat secrets.yaml 
```
В выводе должно быть видно секцию sops которая появилась, если она появилась то файл зашифрован успешно.
#### Настройка или включение сервисов
Настройка нужного сервера находится в вкладке services в документации. Для отключения сервера необходимо закомментировать или удалить строку с путем к сервису в `default.nix`.
Однако если сервис имеет настройку в других сервисах на примере `nginx.virtualHosts`, то это может привести к поломке работы сервера. 

В конфигурации имеется импорт на два независимых сервиса, stories_site и bio. У них уже указаны условия если они отсутствуют. Если они вам не нужны то удалите строки и добавьте свои сервисы
#### Подключение домена
Если имеется домен и открытые порты для необходимого айпи адреса то в `services/nginx/domain.nix` необходимо указать переменные домена и так же почты для автоматического согласия для выдачи сертификатов домена. Если домен отсутствует и нету цели хостинга сайта за пределами локальной сети, и необходима только локальная сеть то нужно выполнить эти настройки в `nginx/default.nix`
```nix
{ ... }: {
  # Комментируем импортирование файла настройки выдачи сертификата
  #imports = [ ./domain.nix ];
  
  services.nginx = {
    enable = true;
    /* отключаем полностью настройку базового домена
    virtualHosts."sophron.ru" = {
      enableACME = true;
      forceSSL = true;
      default = true;
      root = ./bio;
    };*/
  };
}
```
### Применение конфигурации и перезагрузка
#### Применение конфигурации
Если все этапы были сделаны и конфигурация полностью готова к установке то выполняем следующую команду
```sh
cd ~
sudo nixos-install --root /mnt --impure --flake /mnt/home/server/nixosConfigs#название_хоста
```
#### Установка паролей
после успешной установки применяем пароль на пользователя server, root, и через chroot так же устанавливаем пароль пользователям samba.
```
sudo passwd root
sudo passwd server

sudo nixos-enter --root /mnt
chroot -> # smbpasswd -a пользователь_самбы
chroot -> # exit
```
#### Размонтирование и перезагрузка
```
# размонтируем диск с системой
sudo umount -R /mnt
sudo reboot
```

### (Дополнительно) команда для применения конфигурации в системе
Так как внутри директории имеются независимые сервисы для работы то обновлять конфигурацию необходимо через `path:`, если конфигурация будет применяться без указания `path:` то независимые сервисы указанные в .gitignore будут игнорироваться. 
```sh
sudo nixos-rebuild switch --impure --flake path:/home/server/nixosConfigs
```
