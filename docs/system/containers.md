#### Контейнеризация
- файл: `system/docker.nix`
- импортированные модули: `inputs.arion.nixosModules.arion`
- использующиеся модули: `virtualisation.docker` `virtualisation.arion`

**Описание**:
данный файл описывает включение докера как системы для контейнеризации, так же указывается для arion использование докера.

**Определения**:
- **docker** - Программа упаковывающая программы, сервисы в контейнеры.
- **arion** - Инструмент запуска контейнеров использующий язык Nix использующий Docker в качестве бекенда. Имеет поддержку podman.
