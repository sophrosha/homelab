#### Безопасность
- Файлы: `system/fail2ban.nix` `system/firewall.nix`
- использующиеся модули: `services.fail2ban` `networking.firewall`

**Описание**:
Безопасность состоит в включенном фаерволе и настроенном fail2ban для ssh сессии на случай несанкционированного подключения в сеть tailscale.

**Фаервол**:
Имеет разрешенный интерфейс tailscale, а так же UDP порт.
В включенном фаерволе открыты только порт для старых и новых подключений по протоколу HTTP.

**Fail2ban**:
Включены попытки для ssh и для снова атакующих айпи адресов, так же имеется игнорирование айпи адресов которые находятся либо в локальной сети, либо в 0 подзоне.
