#### Правила для каталогов пользователя
Расположение: `system/rules.nix`
Использующееся опции: `systemd.tmpfiles.rules`

**Пример правила**:
```nix
systemd.tmpfiles.rules = [
  "z /path/to/file 0000 user group - -"
];
```

**Обозначения**:
- `z` принудительно применяет правила директории вне зависимости от ее вида.
- `/path/to/file` указание пути к тому файлу, которому надо установить правило.
- `0000` устанавливает правила доступа в зависимости от цифр. пример 0750 устанавливает владельцу полные права, группе только чтение и запись, остальные не могут прочитать.
- `user` пользователь который будет владельцем файла/каталога.
- `group` устанавливает группу которая будет работать по установленным файлам.
