## Введение
### Принцип IaC
Infrastructure as Code - метод организации сервера через описание инфраструктуры сервера как единый код.
Данный HomeLab спроектирован на базе операционной системы NixOS и языка Nix. Обеспечивая полную работу данного метода. В связке с блокировочным файлом конфигурации `flake.lock` обеспечивается строгая воспроизводимость конфигурации, а так же детерминизм при новых изменениях, вносимых мейнтейнером ПО.
### Характеристики сервера
**Железо:**
- *Процессор:* Intel Core 2 Duo E7500
- *Видеокарта:* Nvidia GTX 460
- *Оперативная память:* 6GB типа DDR2-667
- *Материнская плата:* Asus P5K
- *Диски:* 128GB SSD/500GB HDD
- *Сетевая карта:* Atheros L1 Gigabit Ethernet

**Интернет:**
Сервер определен в локальной сети как 192.168.0.102, по шлюзу 192.168.0.1/24. Для удаленного администрирования на сервере предусмотрен overlay-mesh VPN на базе Tailscale.
### Схема HomeLab
Конфигурация разделена на несколько смысловых частей. В качестве входной точки используется `flake.nix`, отвечающий за фиксацию изменений зависимостей, включения пакетов из неофициальных источников и импорт конфигурационных файлов. Базовые системные настройки и импорт остальных конфигураций вынесены в отдельный конфигурационный файл `default.nix`

**Структура конфигурационных файлов**
```
homelab
| - default.nix : Базовая настройка операционной системы(сеть, пользователь, ssh)
| - flake.nix : Импортирование конфигурации, и инструментов недоступных в репозиториях
| - flake.lock : Сохранение детерменизма и воспроизводимости
| - hw-config.nix : Файловые системы, архитектура
| - secrets.yaml : секретные ключи сервисов
| - .sops.yaml : конфигурация с публичным ключом для секретов
| - system/ : Системные конфигурации(фаервол, правила директорий)
|    | - docker.nix
|    | - docker-services/
|    |    \ - ...
|    | - fail2ban.nix
|    | - firewall.nix
|    \ - rules.nix
\ - services : Конфигурации сервисов
     | - grafana.nix
     | - nextcloud.nix
     | - pihole.nix
     | - tailscale.nix
     | - jellyfin.nix
     | - samba.nix
     | - syncthing.nix
     | - zapret.nix
     | - stories-site/
     |    \ - ...
     \ - nginx/
          | - default.nix
          | - domain.nix
          \ - bio/
               \ - ...
```
