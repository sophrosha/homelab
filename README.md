# ❄️ Homelab server
## Описание
Сервер работающий на базе операционной системы NixOS расположенный на территории моей квартиры. 

В данном репозиторий описаны конфигурационные файлы сервисов которые работают 24/7
## Запущенные сервисы
```
Security: firewall, fail2ban
Network: tailscale, zapret, pi-hole, nginx
DevOps: docker, arion, grafana, prometheus
Media: jellyfin
Files: nextcloud, qbittorrent, samba, syncthing
Indexators: jackett + flaresolverr
My: bio, stories.sophron.ru
```
